# VB-004 — Print and PDF Brand Template Standard

> **Two rules govern this entire document, in this order.**
>
> 1. **A statutory document conforms to its instrument.** Where the prescribed form dictates
>    layout, field order or wording, the instrument wins and brand yields completely.
> 2. **Everything not dictated is branded consistently.** A customer holding an intake receipt,
>    an invoice and a warranty certificate should see one company.

---

## 1. Purpose

| | |
|---|---|
| **What this governs** | Page geometry, brand furniture, type, colour and bilingual layout for all 44 `DT` templates |
| **What it does not govern** | What each document says (`DT-002`…`DT-044`); the document-content standard (`DT-001`); statutory content requirements (`MD-037`, the `DT` files themselves) |
| **What breaks without it** | 43 templates authored to no standard produce 43 inconsistent legal documents |

**Relationship to `DT-001`.** `DT-001` is the **content** standard for documents — what a
template must specify. `VB-004` is the **visual and structural** standard — how the page is
built. `DT-001` cites this file; neither restates the other (`CP-01`).

---

## 2. Scope

**In scope:** A4 documents, thermal receipts, labels, and PDFs generated by the ERP.

**Out of scope:** on-screen UI (`VB-003`), email (`VB-005`), marketing collateral (`CB-001` §8
continues to govern), and the barcode/QR data contract (`DT-044`).

## 3. Output formats

| Format | Size | Used for | Renderer constraint |
|---|---|---|---|
| **A4 portrait** | 210 × 297 mm | Invoices, estimates, contracts, reports, certificates, statements | Default |
| **A4 landscape** | 297 × 210 mm | Wide tabular reports, manifests, league tables | Exception; requires justification |
| **A5 portrait** | 148 × 210 mm | Intake receipts, gate passes, collection receipts | Branch printers |
| **Thermal 80 mm** | 80 mm × variable | Counter receipts, payment receipts, token slips | **Monochrome, 203 dpi, no greyscale fills** |
| **Thermal 58 mm** | 58 mm × variable | Rider handheld receipts | Monochrome, narrowest usable width |
| **Label 50 × 25 mm** | — | Device tags, part bin labels | Per `DT-044` |
| **PDF/A-3** | — | **Archived statutory documents** | Long-term retention (`LG-009`) |

| # | Rule |
|---|---|
| **F-01** | Every `DT` template declares its format in front matter. A template rendered to an undeclared format is untested |
| **F-02** | Statutory documents that must be retained — VAT records for at least five years — are archived as **PDF/A-3** with embedded fonts, not as a screen PDF |
| **F-03** | Thermal output is **monochrome only**. No colour, no greyscale, no logo unless it renders legibly at 203 dpi |
| **F-04** | A4 is the default. Any other format requires a stated reason in the template |

## 4. A4 page geometry

```
┌──────────────────────────────────────────────────┐  ← 15 mm top margin
│  [LOGO 18mm]                    DOCUMENT TITLE   │  Header zone — 25 mm
│  Legal entity · BIN · address                    │
├──────────────────────────────────────────────────┤  ← 1pt rule #E9ECEF
│                                                  │
│  PARTY BLOCK          │  DOCUMENT META           │  Party zone — 30 mm
│  Customer name        │  No.  SR-2026-114882     │
│  Address              │  Date 14/08/2026         │
│  BIN / TIN            │  Branch  Shewrapara      │
│                                                  │
├──────────────────────────────────────────────────┤
│                                                  │
│  BODY                                            │  Body zone — flexible
│  Line items, narrative, tables                   │
│                                                  │
├──────────────────────────────────────────────────┤
│  TOTALS / SUMMARY                    right-aligned│  Summary zone — 25 mm
├──────────────────────────────────────────────────┤
│  STATUTORY BLOCK                                 │  Statutory zone — as required
│  Declarations, terms reference, VAT wording      │
├──────────────────────────────────────────────────┤
│  SIGNATURE ZONE          │  QR / barcode  25mm   │  Signature zone — 30 mm
├──────────────────────────────────────────────────┤  ← 1pt rule
│  Footer · page n of m · document ref · hotline   │  Footer — 12 mm
└──────────────────────────────────────────────────┘  ← 15 mm bottom margin
```

| Zone | Height | Rule |
|---|---|---|
| Margins | 15 mm all sides | 20 mm left where documents are filed in a binder |
| Header | 25 mm | Logo left, document title right. Present on **every** page |
| Party block | 30 mm | Two columns: counterparty left, document metadata right |
| Body | Flexible | Minimum 100 mm on the first page |
| Summary | 25 mm | Right-aligned, tabular figures |
| Statutory block | As the instrument requires | **Never split across a page break** |
| Signature | 30 mm | Present only where a signature is captured or expected |
| Footer | 12 mm | Page n of m, document reference, hotline 16743. On **every** page |

| # | Rule |
|---|---|
| **G-01** | Header and footer repeat on every page. A page 3 that cannot be identified is a lost page |
| **G-02** | `Page n of m` is mandatory on all multi-page documents. A statutory document without it cannot be shown to be complete |
| **G-03** | The document reference from `MD-040` appears in the footer of every page |
| **G-04** | The statutory block never splits across pages. If it does not fit, it moves whole to the next page |
| **G-05** | Totals never appear alone on a continuation page without at least the last two line items above them |
| **G-06** | Tables repeat their header row on every page |

## 5. Brand furniture

| Element | Specification |
|---|---|
| **Logo** | 18 mm width, top-left of the header zone. Clear space = height of the "1" (`CB-001` §2.3). Minimum print size 25 mm applies to standalone use; 18 mm is permitted in a fixed header where the mark is repeated and the entity name is set beside it |
| **Logo, thermal** | Icon mark only, or omitted where 203 dpi cannot render it legibly. Test per printer model |
| **Logo, monochrome** | `CB-001` §2.2 monochrome version for single-colour and fax output |
| **Rules and dividers** | 1 pt, `#E9ECEF`. On thermal, a row of dashes |
| **Colour** | Header rule `#1E5F8A`. No colour fills. No gradients. No background tints — they consume toner and photocopy as grey |
| **Watermark** | `DRAFT`, `COPY`, `VOID`, `SPECIMEN` only. 45°, `#E9ECEF`, behind content, never obscuring a statutory field |
| **Page background** | White. Always |

> **Why no colour fills.** These documents are photocopied, faxed, scanned and re-printed on
> branch printers of unknown condition across 51+ sites. A design that depends on colour becomes
> illegible on the third copy. It also fails `CG-011` CL-01 — colour is never the only signal.

## 6. Typography for print

Print type differs from screen type. `VB-003` §7 does not apply here.

| Token | Size | Weight | Leading | Use |
|---|---:|---:|---:|---|
| `doc-title` | 14 pt | 700 | 1.2 | Document title in the header |
| `doc-subtitle` | 11 pt | 600 | 1.3 | Sub-type, copy designation |
| `section` | 10 pt | 600 | 1.3 | Section headings |
| `body` | **9 pt** | 400 | 1.4 | Narrative and clauses |
| `table` | **8 pt** | 400 | 1.25 | Line items |
| `table-header` | 8 pt | 600 | 1.25 | Column headers |
| `numeric` | 9 pt | 500 | 1.25 | **Tabular figures, right-aligned** |
| `legal` | **7 pt** | 400 | 1.3 | Terms and statutory declarations |
| `caption` | 7 pt | 400 | 1.3 | Footnotes, footer |
| `thermal` | 9–11 pt | 400/700 | 1.3 | Monospace on thermal |

| # | Rule |
|---|---|
| **T-01** | **7 pt is the absolute floor in English.** Bengali is higher — see §7 |
| **T-02** | Typeface is **Inter** (`CB-001` §4.1), embedded in the PDF. A statutory document that renders in a substituted font on the recipient's machine is not the document we issued |
| **T-03** | All monetary and quantity values use `numeric` with tabular figures, right-aligned, two decimals for money (`05-06` §9) |
| **T-04** | Identifiers, references and serials are set in a monospaced face at `table` size — they are transcribed by hand |
| **T-05** | Never justify body text. Ragged right; justification creates rivers at 9 pt in narrow columns |
| **T-06** | Never letter-space or condense to fit. Reduce content or add a page |
| **T-07** | Legal text at 7 pt is the minimum any reader should be asked to read. Do not use it to hide length |

## 7. Bilingual layout

34 of the 44 `DT` templates are bilingual (`CG-010` §3.2). Bengali type rules are `VB-009`;
this section governs **layout**.

### 7.1 The three patterns

| Pattern | When | Layout |
|---|---|---|
| **Stacked** | Field labels on forms and receipts | Bengali label above, English label below in `caption`, or the reverse per `BN-007` |
| **Parallel columns** | Terms, declarations, statutory blocks | Two columns, Bengali left, English right, aligned at paragraph level |
| **Separate pages** | Long legal documents | Bengali pages then English pages, each complete, with a precedence clause |

### 7.2 Rules

| # | Rule |
|---|---|
| **BL-01** | The pattern is declared per template, not chosen per field |
| **BL-02** | **Bengali expands 20–40%.** Column widths are set for the Bengali, not the English (`CG-010` BC-01) |
| **BL-03** | Bengali sets one size larger than the English equivalent, or at the `VB-009` minimum, whichever is larger |
| **BL-04** | Do-not-translate items — `Mushak 6.3`, `BIN`, brand names, references — stay in Latin script inside Bengali text (`BN-004`) |
| **BL-05** | Numerals follow the `BN-007` policy. **Statutory documents use Arabic numerals** regardless, because they are transcribed into government systems |
| **BL-06** | Where a statutory instrument prescribes a language, that language is used exactly. A prescribed Bengali form is not "translated into English alongside" unless the instrument permits it |
| **BL-07** | Long legal documents carry a precedence clause stating which language governs in a dispute (`CG-010` §4.1) — **pending Legal confirmation** |
| **BL-08** | Bengali rendering is **physically tested on every supported printer model** before release (`05-06` §9). Conjunct breakage on a specific printer is a real and common failure |

## 8. Statutory documents

`DT-010`…`DT-014` and the other Class A templates. **Brand yields entirely.**

| # | Rule |
|---|---|
| **S-01** | Where the instrument prescribes a form, that form is reproduced exactly — field order, labels, wording, position |
| **S-02** | Brand furniture is added only in space the instrument leaves free |
| **S-03** | The mandated title is set as the instrument writes it, including capitalisation (`CG-003` §1.2 exception) |
| **S-04** | Every mandated element is listed in the `DT` file with its source and verification date (`CG-008` DT-e) |
| **S-05** | The rendered output is verified against the instrument, not only the specification (`CG-007` G3 + G6) |
| **S-06** | A statutory template is version-pinned to its fiscal year (`CG-006` §4.1) |
| **S-07** | Sequence numbering is gap-free, branch-aware and auditable (`MD-040`, `05-02` DM-11) |
| **S-08** | Archived as PDF/A-3 with embedded fonts, retained per `LG-009` — VAT records for at least five years |

### 8.1 Mushak 6.3 — the reference case

The NBR-prescribed VAT tax invoice. Mandated elements include supplier and buyer identity with
BIN, description, quantity, unit price, value and VAT amount, in the prescribed layout, generated
at the point of sale.

| Zone | Treatment |
|---|---|
| Header | Prescribed title. Logo permitted only in free space beside it |
| Party block | Prescribed field set and order. No re-ordering for visual balance |
| Body | Prescribed line-item columns |
| Statutory block | Prescribed declarations, verbatim |
| Footer | Document reference and page n of m permitted |
| Brand colour | **None** |

> Full content requirements are in `DT-010`. This file governs only where the brand may and may
> not appear on it.

## 9. Thermal receipts

The most constrained output and the most frequently issued.

| # | Rule |
|---|---|
| **TH-01** | 80 mm and 58 mm widths. Design for 58 mm and let 80 mm have margin |
| **TH-02** | Monochrome. No greyscale — thermal greyscale is dithering and it smudges |
| **TH-03** | Monospaced type, 9–11 pt. Bold for emphasis; there is no italic |
| **TH-04** | Logo as icon mark only, and only where legible at 203 dpi on that printer model |
| **TH-05** | Dividers are dashes, not rules |
| **TH-06** | QR code minimum 20 mm square, with a quiet zone (`DT-044`) |
| **TH-07** | **Thermal paper fades.** Any receipt that must be retained states "Keep this receipt" and the equivalent record is available in the portal |
| **TH-08** | Bengali on thermal is tested per printer model. Some 58 mm printers cannot render conjuncts at all — where a model fails, that model does not issue Bengali receipts and the branch is issued a compliant model |

## 10. Accessibility of digital documents

PDFs delivered digitally are content and are subject to `CG-011`.

| # | Rule |
|---|---|
| **AC-01** | Digital PDFs are **tagged** — heading structure, reading order, table headers |
| **AC-02** | Document language is declared; language changes within are marked (`CG-011` BA-02) |
| **AC-03** | Every image and logo has a text alternative |
| **AC-04** | Text is real text, never an image of text |
| **AC-05** | Colour is never the only signal (`CG-011` CL-01) |
| **AC-06** | The document title is set in PDF metadata, not left as the file name |
| **AC-07** | Reading order is verified for bilingual parallel-column layouts, which commonly interleave wrongly |

## 11. Do and do not

| Do not | Do |
|---|---|
| Put a coloured header band on an invoice | Use a 1 pt `#1E5F8A` rule |
| Set body text below 9 pt to fit on one page | Add a page |
| Use `#39B1DF` for any text | It fails contrast (`VB-003` §3). Use `#1E5F8A` or `#212529` |
| Size bilingual columns for the English | Size for the Bengali; it is 20–40% longer |
| Let the statutory block split across pages | Move it whole |
| Rely on colour to distinguish a total from a subtotal | Use weight and a rule |
| Omit page n of m on a two-page invoice | Always include it |
| Assume Bengali renders on every branch printer | Test per model before release |
| Use a screen PDF for statutory archive | Use PDF/A-3 with embedded fonts |
