## Standing rules honoured here

- **DE-18/DE-19** — verification is a script: exit non-zero on failure, print
  the remedy; a developer does not begin work until it is green.
- **IR-07 / BE-007 LX-03 / DE-06** — every version pinned in
  `tooling/versions.lock`; verified digests for downloaded artefacts
  (wkhtmltox, Noto Sans Bengali) with fail-closed hash checks.
- **DE-01** — only the toolchain and Docker live on the host; PostgreSQL,
  Redis, object storage and Odoo are containerised (T10 enforces port
  hygiene 5432/6379/9000).
- **DE-12 / SC-009** — full-disk encryption is non-negotiable; on Windows the
  control is BitLocker on the OS volume (check T03).
- **TR-07** — Bengali rendering capability is a workstation requirement
  (Noto Sans Bengali + Nirmala UI), not a font setting.
- No credentials are read, stored or emitted by any artefact in this tree.
