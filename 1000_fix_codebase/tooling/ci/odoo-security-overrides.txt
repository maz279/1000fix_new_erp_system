# =============================================================================
# tooling/ci/odoo-security-overrides.txt - Odoo 19 runtime security overrides
# (R01 re-audit 2026-10-22; policy: docs/guides/odoo-runtime-dependency-security.md)
#
# vendor/odoo/requirements.txt is READ-ONLY (FF-03 vendor-clean). Its Python
# 3.12 pins are the Ubuntu 24.04 "Noble" package set and carried 130 known
# vulnerability entries (80 distinct advisories) in 14 packages (pip-audit
# over the resolved Linux set, 2026-10-22). This file is applied
# with uv's --override, which REPLACES every requirement on the named package
# (direct and transitive), markers included:
#
#   uv pip install -r vendor/odoo/requirements.txt \
#       --override tooling/ci/odoo-security-overrides.txt
#
# Used by every CI job that installs Odoo's requirements and by
# infra/docker/odoo/Dockerfile. Never install the Odoo requirements without it.
#
# Selection rules (in order):
#   1. A package that is ALSO in the root uv.lock is pinned to EXACTLY the
#      locked version - `uv run` re-syncs locked packages, so any other value
#      leaves CI with two competing versions (finding B). Enforced by
#      tooling/tests/test_odoo_security_overrides.py.
#   2. Else the version Odoo 19 itself pins for a newer Python, if patched.
#   3. Else the LOWEST version that clears every known advisory.
# Keep the markers: an override without `sys_platform != 'win32'` would force
# a Linux-only package onto Windows workstations.
# =============================================================================

# --- PDF library: PyPDF2 -> pypdf --------------------------------------------
# PyPDF2 is abandoned (last release 3.0.1): CVE-2023-36464 is fixed only in
# its successor pypdf (3.9.0), so no PyPDF2 version is clean. Odoo 19 already
# supports pypdf (odoo/tools/pdf/_pypdf.py; it is Odoo's own pin for py3.13+,
# PyPDF==5.4.0 - not patched). The never-true marker REMOVES PyPDF2;
# odoo.tools.pdf then falls through from _pypdf2_2 to _pypdf.
# pypdf 6.21.1 is the lowest release clearing all 56 pypdf advisories
# (CVE-2025-55197 ... CVE-2026-113786).
# Note: OCA report_py3o (not installed by any cd_* addon) imports PyPDF2
# only for multi-report merging and degrades to a debug log without it.
pypdf2 ; sys_platform == 'never'
pypdf==6.21.1
