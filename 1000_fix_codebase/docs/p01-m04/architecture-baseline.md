## Entity ownership rulings (T08)

From `AR-008` §2.2 / `AR-008-F-01`: **34 entities owned by more than one
specification** (e.g. `fix.contract.cost` claimed by M08, M53 **and** M54) and
**34 portal-referenced entities owned by nobody**. Ruling pattern per `AR-005`:
