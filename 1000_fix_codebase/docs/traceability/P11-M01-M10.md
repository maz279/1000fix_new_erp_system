## Key deliverables

### Data governance (P11-M02)
- fix.data.entity: the data catalogue over owned entities (DA-002) with
  owner module (FF-27), steward (DA-003: named people), classification
  (DA-005), and retention (DA-006). NFR-086c enforced: residency-
  classified data must NEVER appear in the warehouse.
- fix.data.lineage: source-to-target lineage tracking (DA-003) with
  transformation logic.
- fix.data.quality.rule: DA-008 DQ monitoring with thresholds and
  alerting — `action_check()` fires `data_quality.failing` events.

### IoT (P11-M03)
- fix.iot.device: registry on M17/M45 with telemetry-driven health,
  unhealthy transitions raise alerts automatically.
- fix.iot.telemetry: time-series at volume (50k events/minute design).
- fix.iot.alert: IoT alerting with severity.
- fix.predictive.maintenance: the PdM model wired to M26's ML gateway;
  predicted failures create preventive work orders through M02 dispatch.

### E-Waste (P11-M05)
- fix.ewaste.collection: journey 10 (collection -> triage -> destruction
  -> recycling -> disposal certificate) with the M06 wipe gate before
  destruction and ESG CO2 metrics.
- fix.esg.metric: ESG metrics (CO2, e-waste, refurbished, energy)
  feeding M25's reporting.

### Speech-to-text (P11-M04)
- services/stt: Bengali STT with WER (Word Error Rate) accuracy
  measurement, accuracy classification (production-ready through
  unusable), and the PDPA legal-basis gate (transcription refused
  without a confirmed basis — the DPIA's finding enforced in code).
