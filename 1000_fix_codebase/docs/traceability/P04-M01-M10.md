## Defects found and fixed this phase (audit trail)

1. **11 broken module imports** — `cd_entity_config` (6 files) and
   `cd_party_master` (4 files) referenced by `__init__`, views, security CSVs
   and the P03 traceability record **did not exist on disk**; Odoo would crash
   at install. All 10 models written (zone, geofence, working calendar ×3,
   BD address, country pack ×2, notification config, party hierarchy, consent,
   dedup rule, res.partner ext) + the missing
   `cd_event_outbox/models/__init__.py`.
2. **12 test packages unimportable** — every Odoo module's `tests/` lacked
   `__init__.py` (Odoo's own convention). Added to all 12 modules.
3. **Manifest referencing a missing view** — `cd_device_registry` declared
   `views/fix_device_views.xml` that didn't exist; the other three domain
   modules had no views at all. Views written for all four (fields verified
   against models).
4. **Stray empty scaffold** — `addons/domain/a_service_delivery/cd_crm_ext/`
   (empty directory tree from initial scaffolding) confused the FF-23
   check; removed, and the check hardened to flag manifests-less `cd_*`
   scaffolds explicitly.
5. **WCAG failure in the token source** — error red `#ef4444` gave 3.76:1
   against white text (WCAG 2.2 AA needs 4.5:1). CFM-03 caught it; source
   corrected to `#c62222` (5.75:1), realisations regenerated.
6. **Credential-in-URL guard gap** — the dispatcher's SMS adapter validated
   URL userinfo but not credential-bearing query strings; both now refused
   (credentials travel in headers only).
7. **M06 deepening pass** — the leads menu referenced a `menu_ws_party` id
   that never existed; fixed to `menu_fix_party_root`. The portal-contract
   checker (FF-27) now prevents this entire class at pre-merge. `fix.role`
   carried a duplicated `operating_unit_ids` field declaration (silently
   overridden) — removed. `cd_catalogue` gained the missing `cd_rbac_ext`
   dependency its workspace gate requires (platform→platform, FF-17-clean).
8. **Six modules shipped i18n-able screens without bn_BD.po** — the
   strengthened FF-25 caught entity config, party, catalogue, rbac, outbox,
   MDM, document and employee cores with templates but no Bengali;
   `generate-platform-po.py` closed all eight to 100% (+2 domain top-ups).
