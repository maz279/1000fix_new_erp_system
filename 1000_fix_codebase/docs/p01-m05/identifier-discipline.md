## T09/T10 — Backlog structure + epic load

Hierarchy: **Wave → Epic (`M`/`P`) → Feature (`CD-<UNIT>-<nn>`) → Story
(`ST-<CD-ID>-<nn>`)** — no new identifier space; stories derived
(`SPR-02`). The **epic load file is `cd-register.yaml` itself** (id, unit,
type, wave, PW — plus the tier from the regenerated graph); the programme tool
(`P01-M01-T06`) imports it directly. `CDR-08` is enforced by `FF-16` from the
first build: an identifier may not appear in a manifest, branch, commit,
backlog item or test case unless it appears in the register.
